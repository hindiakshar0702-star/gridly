Gridly demo — constraint-based layout

Open the panel (bottom-left button) and watch the constraint invariants hold:

  • Margin L → grid origin moves by exactly that amount.
  • Margin R → only the right edge moves; origin stays put.
  • Gutter → only column widths + spacing change.
  • Grid Overlay (column count) → origin never moves.

Toggle Show constraint debug overlay in the panel to see viewport bounds, container bounds, the orange origin marker, and a live stats panel.
