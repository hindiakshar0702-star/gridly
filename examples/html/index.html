Gridly demo

Click the floating Gridly button (bottom-left) to open the panel, or press Ctrl+G to toggle the grid.

Inside the panel you can switch between 18 grid types, themes, device simulators (mobile/tablet/laptop/desktop), tweak margins, gutters, breakpoints, and toggle gridOverlay_n / gutter_n labels.

1. Columns

Classic 12-column grid with 24px gutters.

2. Baseline

Vertical rhythm based on an 8px baseline.

3. Square

Uniform square grid for canvas / dashboard layouts.

4. Dots

Figma-style dot grid for free-form design.

5. Modular

Magazine-style row + column grid.

6. Polar

Radial grid for circular UIs and data viz.

7. Flex

Alignment guides for flexbox layouts.

8. Fibonacci

Phi-based subdivisions with spiral.

9. Diagonal

45-degree cross-hatch grid.
